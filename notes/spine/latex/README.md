# Spine note LaTeX (not the book)

Two-pass PDF for *QGA Spine Note: Quaternion Orders, Hopf, and the Hatcher Lift*.

From the **repository root**:

```bash
./scripts/build_spine.sh
```

Writes `notes/spine/QGA_Spine_Note.pdf` (and `notes/spine/latex/main.pdf`).

This is **not** Release `draft-D` and **not** `book/Kingdom_Come_QGA.pdf`. There is no `--fast` path. Do not run `./scripts/build_latex.sh` for this note.
